# Super Transcriber API Landing Page

This directory contains a static sales page for companies and developers evaluating Super Transcriber API as a ready-to-integrate transcription backend.

Open `index.html` directly in a browser or serve this directory with any static host. The page has no build step, backend dependency, or idle infrastructure cost.

The shared logo is `assets/super-transcriber-mark.svg`: an audio waveform becoming transcript lines, designed through a read-only Claude consultation and integrated by Codex. All four page headers reference this single vector asset. `assets/favicon.svg` uses the same geometry in a deeper gold for contrast on light and dark tab backgrounds. Both assets are self-contained, with no fonts, scripts, gradients, or external dependencies.
