# Super Transcriber API

Super Transcriber API is a developer-facing, privacy-conscious transcription backend for teams that want a clean REST API on a cost-first AWS serverless stack. It accepts private S3 uploads, starts asynchronous Amazon Transcribe jobs, records status and usage in DynamoDB, and can be deployed as a hosted API or into a customer-owned AWS account with the same Terraform.

## API Quickstart

Deploy the stack, then set:

```bash
export API_BASE_URL="$(terraform -chdir=terraform output -raw api_endpoint)"
export ADMIN_TOKEN="replace-with-your-admin-token"
```

Create an API key. The plaintext key is returned once.

```bash
curl -sS -X POST "$API_BASE_URL/v1/api-keys" \
  -H "authorization: Bearer $ADMIN_TOKEN" \
  -H "content-type: application/json" \
  -d '{"customerName":"Acme Dev","keyName":"Local dev key"}'
```

Presign an upload.

```bash
export API_KEY="stapi_example_key"

curl -sS -X POST "$API_BASE_URL/v1/uploads/presign" \
  -H "x-api-key: $API_KEY" \
  -H "content-type: application/json" \
  -d '{"fileName":"meeting.mp3","contentType":"audio/mpeg","fileSizeBytes":1048576}'
```

Upload the file with the returned `uploadUrl`.

```bash
curl -X PUT "$UPLOAD_URL" \
  -H "content-type: audio/mpeg" \
  --upload-file ./meeting.mp3
```

Start transcription with the returned `s3Key`.

```bash
curl -sS -X POST "$API_BASE_URL/v1/transcriptions" \
  -H "x-api-key: $API_KEY" \
  -H "content-type: application/json" \
  -d '{"s3Key":"customers/cust_123/uploads/job_123/meeting.mp3","fileName":"meeting.mp3","durationSeconds":600,"speakerCount":2}'
```

Poll and list jobs.

```bash
curl -sS "$API_BASE_URL/v1/transcriptions/$JOB_ID" -H "x-api-key: $API_KEY"
curl -sS "$API_BASE_URL/v1/transcriptions?limit=20" -H "x-api-key: $API_KEY"
```

## Architecture Summary

Requests enter through API Gateway HTTP API and are routed to small Node.js 20 Lambda handlers on arm64. DynamoDB uses a single-table PAY_PER_REQUEST model for customers, hashed API keys, jobs, Transcribe mappings, and monthly usage counters. S3 stores uploaded audio and transcript JSON in private buckets with lifecycle expiration. Amazon Transcribe runs asynchronous jobs, and EventBridge invokes a completion Lambda when jobs finish or fail.

## AWS Services Used

- API Gateway HTTP API
- AWS Lambda, Node.js 20, arm64
- DynamoDB on-demand capacity
- S3 private buckets
- Amazon Transcribe asynchronous jobs
- EventBridge job-state rule
- SQS dead-letter queue for completion handling
- CloudWatch Logs with Terraform-managed 14-day retention
- Optional CloudWatch alarms, disabled by default

## Cost Controls

- No VPC, NAT Gateway, RDS, OpenSearch, queues with idle workers, or fixed monthly compute.
- DynamoDB uses PAY_PER_REQUEST.
- S3 lifecycle rules expire uploads and transcripts.
- Lambda and API Gateway are request driven.
- Default limits are 5 active jobs, 200 MB files, 20 minute audio duration, and 120 monthly transcription minutes.
- Duration is reserved before starting Transcribe. If `durationSeconds` is omitted, the full 20 minute maximum is reserved.

## Security Model

End-user API keys are generated by the admin route, stored only as SHA-256 hashes, and looked up through a key id GSI rather than table scans. The API accepts `x-api-key` or `Authorization: Bearer`. S3 objects are private, public access is blocked, and upload access is granted only through presigned PUT URLs. Every job and S3 key is validated against the authenticated customer id. Errors use `{ "success": false, "error": "...", "code": "..." }`, and handlers do not log raw API keys.

## CI and Deployment Status

The active CI workflow installs Lambda dependencies, runs TypeScript checks, executes Vitest unit tests, bundles Lambda zip files, runs Terraform formatting, initializes Terraform without a backend, validates Terraform, and checks whitespace. AWS deployment is not active by default. An optional manual deployment workflow is stored under `.github/examples`.

## Implemented vs Not Implemented

Implemented: API-key creation, hashed API-key auth, presigned S3 uploads, S3-backed transcription job creation, DynamoDB job storage, cursor pagination, soft deletion, Transcribe completion handling, transcript retrieval, usage counters, Terraform infrastructure, unit tests, and CI.

Not implemented in v1: direct `sourceUrl` ingestion and Stripe billing calls. `sourceUrl` returns `501 NOT_IMPLEMENTED`. Stripe is represented as an optional configuration path and remains disabled unless Stripe environment configuration is supplied.
